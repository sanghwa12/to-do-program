# F03 · 정리 뷰 (오늘 · 날짜 · 우선순위 · 카테고리)

## 목적
쏟아부은 할 일을 **앱이 대신 정리해서** 보여준다.
"계획을 세우는 건 앱, 사용자는 붓기만 한다"를 실현하는 화면.

## 사용자 시나리오
- 앱을 열면 "오늘 할 일"이 먼저 보인다 — 오늘 뭐 하면 되는지 바로 파악.
- 탭(또는 버튼)을 눌러 우선순위순 / 카테고리별 / 날짜별로 바꿔 볼 수 있다.
- 쏟아부을 때 못 붙인 날짜·우선순위·카테고리를 **나중에** 각 할 일에 붙일 수 있다.

- [ ] R9. **기간에서 날짜 제외/추가** (2026-09-28 개편 5단계, 사용자 요청 — "10/6~10/16으로
      설정해 놓은 것에서 10/9를 제외한다든지, 10/19를 추가한다든지"). **할 일·일정 둘 다** (F11 R11).
      - **개념**: 걸리는 날 = (시작~끝 − **제외한 날**) + **추가한 날**.
        기간(시작·끝) 자체는 바뀌지 않고 예외만 따로 기억한다 (`skipDates`, `extraDates`).
        하루짜리·마감·반복에는 없다 (기간에만).
      - **고치는 곳 ① 달력**: 날짜 칸 클릭 → 아래 카드의 **"이 날 빼기"** (기간 항목에만 보임).
        그 날만 빠지고 실행취소 알림(`"제목" 10/9 제외됨`). 추가한 날에서 누르면 추가가 취소된다.
        마지막 남은 하루는 못 뺀다 (버튼이 안 보임 — 어디에도 안 보이는 항목이 되지 않게).
      - **고치는 곳 ② 수정 화면**: 기간일 때만 **"제외할 날 / 추가할 날"** 두 줄.
        날짜를 고르고 [제외]/[추가] 버튼(날짜 칸에서 Enter도 같음) → 아래에 칩으로 쌓이고,
        칩의 ✕로 되돌린다. 수정 화면의 저장을 눌러야 반영 (취소하면 버려짐).
        넣을 수 없는 날(이미 제외한 날, 이미 걸리는 날)이면 버튼이 흐리다.
        기간 안의 날을 "추가할 날"에 넣으면 제외가 풀린다.
      - **자동 정리**: 제외는 기간 안의 날만, 추가는 기간 밖의 날만 남긴다 — 기간을 고쳐
        범위를 벗어난 예외는 화면에서도 바로 빠진다. 기간을 줄여 남은 날이 전부 제외된 날이면
        제외를 무시. 날짜 종류를 기간이 아닌 것으로 바꾸면 예외는 지워진다.
      - **표시**: 달력 칩은 걸리는 날에만. "진행중"은 오늘이 걸리는 날일 때만,
        "N일 지남"은 **마지막으로 걸리는 날** 기준 (추가한 날이 기간 끝보다 뒤면 그 날).
        뱃지의 예외 날짜가 넷 이상이면 `제외 10/7, 10/9, 10/11 외 2일`.
      - **오늘 탭**: 제외한 날에는 "오늘 할 일"·"오늘 일정"에 나오지 않는다. 일정은 다음으로
        걸리는 날이 7일 안이면 "다가오는 일정"에. 기간이 끝나고 추가한 날을 기다리는 동안의
        할 일은 밀린 것으로 치지 않는다.
      - 할 일 ↔ 일정 변환(F11 R9), 백업 왕복(F06 R6), 구글 캘린더(F12)에도 예외가 따라간다.
      - 계산은 `src/span.js` (순수 함수, node 검증) — 할 일·일정이 같은 규칙을 쓴다.
