# F11 · 노트 (통합 — 기록 + 일정 공지)

> **2026-08-03 대통합 (사용자 결정 A안)**: 📎 참고 + 📝 노트 + 📢 일정 공지를
> 하나의 "노트" 시스템으로 합침. "어디에 쓰지?" 고민(입력 마찰)을 없애기 위함.
> F08(알아둘 것)은 이 문서로 흡수됨.

## 개념
**노트 = 자유 글 (한 줄이든 여러 줄이든) + 날짜는 선택 속성.**
- 날짜 있음 → 일정 공지처럼 동작: 달력에 📢 표시, 지나면 흐림, 오늘이면 오늘 탭 한 줄
- 날짜 없음 → 그냥 기록 (최신 수정순)
- "할 일(체크 있음) vs 노트(체크 없음)" 구분은 그대로 유지 — 앱의 근간.
  노란 메모판(날짜 없는 할 일)은 이 통합과 무관하게 유지.

## 데이터 모델
```ts
type Memo = {
  id: string;
  text: string;      // 자유 글 (첫 줄 = 제목 역할)
  date?: string;     // 선택: "그 일이 있는 날" (있으면 일정 공지 성격)
  createdAt: string;
  updatedAt: string; // 목록 정렬 기준
};
```
- **자동 이사 (v5→v6)**: 기존 알아둘 것(notes)의 항목을 노트로 복사
  (제목+설명 → 첫 줄+둘째 줄, 날짜 유지) 후 notes 테이블 제거. 데이터 무손실.

## 요구사항 (검증 항목)
- [ ] R1. 기존 notes 데이터가 memos로 자동 이사된다 (앱 첫 실행 시, 무손실).
- [ ] R2. 정보 탭 = **입력줄 하나 + 통합 목록**:
      - 입력줄: 텍스트+Enter (날짜 자동 인식 — 지난 날짜 그대로, 반복 인식 없음)
      - 긴 글은 "+ 새 노트"로 에디터 열어 작성
- [ ] R3. 목록 두 구역 (같은 데이터, 표시만 구분):
      - **📅 일정** (날짜 있음): 임박한 순, 지난 것은 흐리게 맨 아래
      - **📝 노트** (날짜 없음): 카드(첫 줄 제목 + 미리보기 + 수정일), 최신순
- [ ] R4. 아무 항목이나 클릭 → 에디터 (여러 줄 textarea + 날짜 입력 + 저장/취소/삭제).
      날짜를 붙이거나 떼면 구역이 자동으로 바뀐다.
- [ ] R5. 날짜 있는 노트는 **달력에 📢 칩**(첫 줄), 날짜가 오늘이면 **오늘 탭 맨 위 한 줄**.
- [ ] R6. 삭제는 확인 + 실행취소.
- [ ] R7. 내보내기: 날짜 있으면 `- 📢 첫줄 📅 날짜` + 나머지 📝 줄, 없으면 📝 블록.
      가져오기는 📢·📎·📝·📓 줄 건너뜀 (기존 백업 파일도 안전).
