# F11 · 노트 (통합 — 기록 + 일정 공지)

> **2026-08-03 대통합 (사용자 결정 A안)**: 📎 참고 + 📝 노트 + 📢 일정 공지를
> 하나의 "노트" 시스템으로 합침. "어디에 쓰지?" 고민(입력 마찰)을 없애기 위함.
> F08(알아둘 것)은 이 문서로 흡수됨.

## 개념
**노트 = 자유 글 (한 줄이든 여러 줄이든) + 날짜는 선택 속성.**
- 날짜 있음 → 일정 공지처럼 동작: 달력에 📢 표시, 지나면 흐림, 오늘이면 오늘 탭 한 줄
- 날짜 없음 → 그냥 기록 (최신 수정순)
- "할 일(체크 있음) vs 노트(체크 없음)" 구분은 그대로 유지 — 앱의 근간.
  노란 메모판(날짜 없는 할 일)은 이 통합과 무관하게 유지.

## 데이터 모델
```ts
type Memo = {
  id: string;
  text: string;      // 자유 글 (첫 줄 = 제목 역할)
  date?: string;     // 선택: "그 일이 있는 날" (있으면 일정). 기간이면 시작일
  endDate?: string;  // 선택: 기간의 끝 — 있으면 기간 일정 (R8, 2026-09-28)
  time?: string;     // 선택: 시간 "HH:MM" — 기간이 아닐 때만 (R8)
  skipDates?: string[];  // 선택: 기간에서 제외한 날들 — 기간일 때만 (R11)
  extraDates?: string[]; // 선택: 기간 밖에 추가한 날들 — 기간일 때만 (R11)
  createdAt: string;
  updatedAt: string; // 목록 정렬 기준
  doneAt?: string;   // 선택: 완료한 시각 — 있으면 노트 탭에서 안 보임 (R12, 2026-11-26)
};
```
- **자동 이사 (v5→v6)**: 기존 알아둘 것(notes)의 항목을 노트로 복사
  (제목+설명 → 첫 줄+둘째 줄, 날짜 유지) 후 notes 테이블 제거. 데이터 무손실.

- [ ] R2. 정보 탭 = **입력줄 하나 + 통합 목록**:

- [ ] R3. 메모 탭 아래 노트 구역에는 **📝 노트(날짜 없음)만**: 카드(첫 줄 제목 + 미리보기 +
      수정일), 최신순.
      - ~~**📅 일정** 목록 (날짜 있음): 임박한 순, 지난 것은 흐리게 맨 아래~~ →
        **2026-09-28 제거 (사용자 결정)**: 일정은 달력·오늘 탭에서 보고 고친다 (R10).
        지난 일정은 달력에서 그 달로 넘겨서 본다.
      - 노트 입력줄에 날짜를 쓰면 일정으로 저장되고 이 구역엔 나타나지 않는다 — 미리보기에
        "달력·오늘 탭에 보여요"라고 알려줌.
- [ ] R4. 아무 항목이나 클릭 → 에디터 (여러 줄 textarea + 날짜 입력 + 저장/취소/삭제).
      날짜를 붙이거나 떼면 구역이 자동으로 바뀐다.
- [ ] R5. 날짜 있는 노트(=일정)는 **달력에 📢 칩**(첫 줄), 그리고 **오늘 탭 맨 위 "📢 일정" 블록**
      (2026-09-28 개편 — 예전엔 오늘 날짜인 것만 회색 한 줄이라 잘 안 보였음):
      - 보고 있는 날짜의 일정 (◀▶로 날짜를 옮기면 그 날 것).
      - 오늘을 볼 때는 **다가오는 일정**(내일~7일 뒤)도 가까운 순으로: `10/1 (목) · 3일 뒤`.
      - 보여줄 일정이 하나도 없으면 블록을 그리지 않는다.
      - **일정 색 = 보라** (사용자 결정): ~~달력 칩, 달력 아래 목록, 오늘 탭 블록에 연보라
        바탕 + 보라 글자~~ → **같은 날 디자인 정리로 "왼쪽의 가는 보라 줄"** 로 바뀜
        (흰 바탕 + 검정 글자. 할 일은 파란 줄 — D00 "종류 색" 절). 입력칸 토글은 그대로.
      - 입력 경로 3곳: 맨 위 입력칸 토글(F02 R16), 달력 날짜 클릭(F07 R9), 메모 탭 노트 입력줄.
- [ ] R6. 삭제는 확인 + 실행취소.
- [ ] R8. **일정에 기간·시간** (2026-09-28 개편 4단계, 사용자 결정):
      - 입력: `학회 10/6~10/16` → 기간 일정, `세미나 10/1 14:00` → 시간 있는 일정.
        세 입력 경로(맨 위 입력칸 토글, 달력 날짜 클릭, 노트 입력줄) 모두 같은 규칙
        (`notes.js`의 `noteDatesFrom`). 예전엔 시작일만 남고 시간은 버려졌음.
      - 에디터: 날짜 옆에 **끝 날짜**(선택)와 **시간**(선택) 칸. 끝 날짜를 넣으면 기간이 되고
        시간 칸은 숨는다 (기간엔 시간 없음 — 할 일과 같은 규칙).
      - 저장 직전 정리(`normalizeNoteDates`): 끝이 시작보다 빠르면 앞뒤 교환, 끝=시작이면
        하루짜리, 날짜를 지우면 끝·시간도 같이 지움.
      - 표시: 기간 일정은 달력의 **시작~끝 모든 칸**에 칩, 오늘 탭 블록엔 기간 중 매일.
        같은 날은 시간 순(시간 없는 것 뒤), 칩·줄 앞에 시간. 일정 목록 뱃지는
        `📅 2026-10-06 ~ 2026-10-16`, 진행 중이면 "· 진행중", "지남"은 **마지막 날** 기준.
        앞날이면 남은 날 `· D-3` (오늘은 `D-day`, 기간은 `시작 D-3` — F03 R12, 2026-11-17).
      - 내보내기: `- 📢 제목 📅 2026-10-06 ~ 2026-10-16` / `📅 2026-10-01 14:00`.
      - 구글 캘린더: 기간은 여러 날 종일 이벤트, 시간 있으면 60분 (F12 매핑 표).
- [ ] R9. **할 일 ↔ 일정 변환** (2026-09-28, 사용자 요청 "기존 할 일을 일정으로 변경 가능하게"):
      - 할 일 수정 화면의 **📢 일정으로 바꾸기** (날짜가 있을 때만 보임),
        일정 에디터의 **할 일로 바꾸기**. 둘 다 지금 화면에 보이는 내용 그대로 바뀐다.
      - 옮겨지는 것: 제목+세부 메모 ↔ 글(첫 줄=제목, 나머지=세부 메모), 날짜·기간·시간.
        마감(~)이던 할 일은 그 날짜의 일정으로, 하루짜리 일정은 "당일" 할 일로.
      - 사라지는 것: 완료 체크, 반복 (일정에 없는 개념). **반복 할 일은 바꾸기 전에 한 번 더 확인.**
      - 바꾼 뒤 아래 알림의 **실행취소**로 원래대로 (바꾸기 전 항목을 통째로 되살림).
      - 저장: 한쪽 보관함에서 지우고 다른 쪽에 **같은 id**로 생성 (한 묶음 — 도중 실패 시
        둘 다 없던 일). 구글 캘린더는 다음 보내기 때 옛 이벤트 삭제 + 새 이벤트 추가로 반영.
- [ ] R7. 내보내기: 날짜 있으면 `- 📢 첫줄 📅 날짜` + 나머지 📝 줄, 없으면 📝 블록.
      가져오기는 📢·📎·📝·📓 줄 건너뜀 (기존 백업 파일도 안전).

- [ ] R10. **달력·오늘 탭에서 일정 수정·삭제** (2026-09-28, 사용자 지적 "달력에서 똑같이
      수정하면 되지" + "오늘 탭에서도 수정되게"):
      일정은 보이는 자리에서 **할 일 줄과 같은 방식**으로 다룬다 — 마우스를 올리면 수정/삭제,
      수정은 그 자리에서 (노트 에디터를 재사용: 글·날짜·끝 날짜·시간·할 일로 바꾸기).
      삭제는 확인 + 실행취소.
      - 달력 아래 목록: 할 일 카드와 같은 틀, 체크박스 대신 📢, 왼쪽 줄이 보라 (할 일은 파랑).
      - 오늘 탭 일정 블록: 한 줄 모양 그대로 (오늘 일정·다가오는 일정 모두), 줄 오른쪽에 버튼.
      - 한 부품(`EventItem`)이 두 모양(카드 / 한 줄 `compact`)을 그린다.
      (그 전까지는 일정을 고치려면 메모 탭 아래 일정 목록까지 가야 했음 — 그 목록은 제거, R3)
- [ ] R11. **기간 일정에서 날짜 제외/추가** (2026-09-28 개편 5단계): 할 일과 **같은 규칙·같은 화면**
      (자세한 규칙은 F03 R9).
      - 달력 아래 일정 카드의 **"이 날 빼기"** + 실행취소, 일정 에디터의 **"제외할 날 / 추가할 날"**
        (끝 날짜가 있을 때만 보임).
      - 달력 📢 칩은 걸리는 날에만, 뱃지는 `📅 2026-10-06 ~ 2026-10-16 · 제외 10/9 · 추가 10/19`,
        "지남"은 마지막으로 걸리는 날 기준.
      - 오늘 탭 일정 블록: 제외한 날엔 "오늘 일정"에서 빠지고, 다음으로 걸리는 날이 7일 안이면
        "다가오는 일정"에 그 날짜로 나온다. 줄의 기간 표기 뒤에도 `· 제외 9/28`.
      - 저장 직전 정리(`normalizeNoteDates`)가 예외도 함께 정리 — 하루짜리가 되거나 날짜를 지우면
        예외도 지워진다.
      - 내보내기: `- 📢 제목 📅 2026-10-06 ~ 2026-10-16 ➖2026-10-09 ➕2026-10-19`.
- [ ] R12. **노트 완료** (2026-11-26, 사용자 요청 — "삭제 말고 완료 기능을. data는 남아있지만
      보이지는 않게"):
      - 노트 탭의 카드 오른쪽 **완료** 버튼, 노트 에디터의 **완료** 버튼 (날짜 없는 노트에만).
        누르면 `doneAt`에 시각을 적고 노트 탭 목록에서 빠진다. **데이터는 지우지 않는다.**
        확인 없이 바로 + 아래 알림의 **실행취소**.
      - 완료한 노트는 **검색(F13)** 에서 그대로 찾아지고 수정일 뒤에 `· 완료` 표시.
        열면 에디터의 버튼이 **완료 취소** — 누르면 노트 탭에 다시 나온다 (수정일은 그대로라 원래 자리로).
      - 삭제는 없애지 않고 에디터 안에 그대로 둠 (잘못 쓴 노트를 지울 길). 목록에서 한 번에 누르는 것은 완료만.
      - 내보내기: 완료한 노트도 백업에 포함, 제목 줄에 `(완료)` 표시 (`### 📝 2026-11-26 (완료)`).
      - 범위 밖(필요해지면): 완료한 노트만 모아 보는 화면, 일정(날짜 있는 노트)의 완료.
