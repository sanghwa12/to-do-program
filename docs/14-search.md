# F13 · 검색

## 목적
쏟아부은 것이 쌓이면 스크롤만으로는 못 찾는다. **단어 하나로 할 일·일정·노트·하루 기록을
한꺼번에 찾고, 찾은 자리에서 바로 고친다.** (평가보고서 2026-08-03의 ④ "찾는 방법이 스크롤뿐" 해소)

## 사용자 시나리오
- "세금계산서 건 언제까지였지?" → 🔍 → `세금` → 할 일·끝낸 할 일·일정이 종류별로 보임.
- "그 출장 정산 언제 했더라?" → `정산` → 끝낸 할 일과 하루 기록의 줄이 날짜와 함께 보임
  → 하루 기록 줄을 누르면 오늘 탭이 그 날짜로 열림.
- 찾은 할 일을 그 자리에서 체크·수정·삭제 → ← 뒤로 (또는 Esc).

## 요구사항 (검증 항목)
- [ ] R1. 상단 제목 줄에 **🔍 버튼** (⋯ 메뉴 왼쪽). 누르면 검색 화면이 열리고 입력칸에 커서.
      **"← 뒤로"** 또는 입력칸에서 **Esc**로 복귀 (휴지통·도움말과 같은 방식).
      빠른 입력창은 건드리지 않음 — 입력 흐름은 그대로.
- [ ] R2. **치는 즉시** 결과가 바뀜 (Enter 불필요). 영문 대소문자 구분 없음.
      띄어 쓴 여러 단어는 **모두 들어간 것만** (예: `출장 정산`).
- [ ] R3. 검색 대상:
      할 일 = 제목 + 세부 메모 (끝낸 것 포함, **휴지통은 제외**) /
      일정·노트 = 글 전체 /
      하루 기록 = "오늘의 계획" 줄 + "계획 외에 한 일" 줄.
- [ ] R4. 결과는 **종류별 묶음 + 개수**로: 📋 할 일 / ✅ 끝낸 할 일 / 📢 일정 / 📝 노트 / 📓 하루 기록.
      결과가 없는 묶음은 숨김. 맨 위에 전체 개수.
- [ ] R5. 결과에서 **바로 다루기**: 할 일은 체크·수정·삭제 (목록과 같은 줄, 실행취소 알림도 같음),
      일정은 수정·삭제, 노트는 누르면 그 자리에 에디터.
      하루 기록 줄은 누르면 **오늘 탭이 그 날짜로** 열림 (날짜·"계획"/"한 일" 표시).
- [ ] R6. 순서: 할 일 = 전체 탭과 같은 급한 순 / 끝낸 할 일 = 최근에 끝낸 순 /
      일정 = 날짜 최신 순 / 노트 = 최근 수정 순 / 하루 기록 = 날짜 최신 순.
- [ ] R7. 검색어가 비면 안내 문구만, 결과가 없으면 "…이(가) 들어간 것이 없어요".

## 관련 제약 (CLAUDE.md 핵심 제약 중 이 기능에 해당하는 것)
- 서버 없음 — 이미 화면에 올라와 있는 데이터(IndexedDB)를 브라우저 안에서 훑음. 새 라이브러리 없음.
- 입력 마찰 최소화 — 빠른 입력창·탭은 그대로. 검색은 버튼 뒤의 별도 화면.

## 관련 파일
- `src/search.js` — 찾기 계산 (화면과 분리된 순수 함수)
- `src/components/SearchView.jsx` — 검색 화면
- `src/App.jsx` — 🔍 버튼, 검색 화면 연결, 오늘 탭 날짜(`dayDate`)를 App으로 올림 (하루 기록으로 이동용)
- `src/index.css` — `.search-*`

## 비고 / 미결정 (지금은 범위 밖)
- 초성 검색(`ㅅㄱㄱㅅㅅ`), 날짜로 찾기(`11/30`), 휴지통 안 검색, 찾은 글자 강조 표시, 단축키(Ctrl+K 등).
- 하루 기록의 예전 "한 줄 회고"(화면에서 제거된 값)는 찾지 않음.
