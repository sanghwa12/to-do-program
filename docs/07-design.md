# D00 · 디자인 원칙 · UI 단순화

> 이 문서는 특정 기능이 아니라 **화면 전체의 생김새를 관리**하는 기획서입니다.
> 기능이 늘수록 화면이 복잡해지기 쉬우니, 여기서 원칙을 정하고 주기적으로 정리합니다.

## 디자인 원칙 (이 앱의 정체에서 나옴)
1. **입력이 주인공.** 입력창이 가장 크고 눈에 띄어야 한다. 다른 요소가 입력을 방해하면 안 됨.
2. **시각적 소음 최소화.** 색·테두리·버튼을 남발하지 않는다. 기본은 무채색, 강조는 딱 필요할 때 1색.
   (종류를 나타내는 색은 넓은 면이 아니라 **가는 줄**로만 — 아래 "종류 색" 절)
3. **자주 쓰는 건 눈에, 드물게 쓰는 건 숨긴다.** (예: 삭제·내보내기·초기화는 평소 눈에 덜 띄게)
4. **한 화면에 한 가지 일.** 목록을 볼 땐 목록에 집중, 편집할 땐 편집만.
5. **컴퓨터 화면 기준**이되, 창을 줄여도 깨지지 않게(반응형) 유지.

## 현재 상태에서 복잡하다고 본 것들 (2026-07-03)
- 각 할 일마다 **수정·삭제 버튼이 항상 보임** → 목록이 버튼으로 빽빽함.
- **뱃지 색이 여러 종류**(마감/진행중/우선순위 3색/카테고리) → 알록달록함.
- 상단 **내보내기·가져오기**, 하단 **휴지통·모두지우기** 등 액션이 곳곳에 흩어짐.
- 탭이 **5개**(오늘/전체/날짜/우선순위/카테고리) → 많게 느껴질 수 있음.

## 단순화 후보 → 적용 내역 (2026-07-03, 사용자 선택 A·B·C)
- **A. 항목 버튼 숨기기** ✅: 평소엔 제목·뱃지만. 마우스 올릴 때(또는 포커스 시) 수정/삭제 노출.
- **B. 색 줄이기** ✅: 강조색(빨강)은 "밀림"에만. 진행중/우선순위/카테고리 뱃지는 회색 기본,
  중요도는 색 대신 글씨 굵기로 구분.
- **C. 액션 정리** ✅: 내보내기·가져오기·휴지통·모두지우기를 상단 **⋯ 메뉴** 하나로 모음(하단 줄 제거).
- **D. 탭 줄이기** ✅ 단계 실행: 날짜 탭(2026-07-15, 달력이 대체) →
  우선순위·카테고리 탭(2026-08-03, 사용자 결정) 제거. 최종 5개:
  오늘/하루/달력/전체/정보.

## 종류 색 = 왼쪽의 가는 줄, 글자는 검정 (2026-09-28 디자인 정리, 사용자 결정)
- **문제(사용자)**: "오늘 일정은 보라색이고 나머지는 다 회색·검은색, 달력에서도 일정만 보라색이라
  이상하다. 글씨는 웬만하면 검정이면 좋겠다 (완료 시 회색은 당연히 괜찮음)."
  원인은 일정만 **넓은 면적**이 연보라 바탕 + 보라 글자라 화면에 혼자 튀는 "섬"이 된 것.
- **정한 규칙** (시안 A·B·C 비교 후 A안 + 사용자 추가 요청):
  1. **바탕은 흰 카드로 통일**, 종류는 **왼쪽의 가는 줄(4px) 색**으로만 구분한다.
     | 종류 | 줄 색 | 보이는 곳 |
     |---|---|---|
     | 할 일 | 파랑 `#4a7dff` | 할 일 카드(오늘·달력·전체 탭), 달력 칩 |
     | 일정 | 보라 `#8a5cf5` | 오늘 탭 일정 블록, 달력 아래 일정 카드, 달력 칩 |
     | 오늘의 계획 | 주황 `#f08c00` | 오늘 탭 하루 기록의 계획 블록 |
     | 실제 한 일 | 초록 `#2f9e44` | 오늘 탭 하루 기록의 실제 한 일 블록 |
     | 끝난 것 (완료·휴지통) | 회색 `#cfcfcf` | 완료한 할 일 카드·칩, 휴지통 |
     (주황·초록은 "알아서 골라 달라"는 요청에 따라 각 제목의 그림 📝·✅ 색에 맞춤.)
  2. **글자는 검정(`#222`).** 회색은 아래에만 쓴다 —
     끝난 것(완료·미룸·휴지통), **보조 글씨**(제목 옆 개수, 완료 시각, 노트 미리보기·수정일),
     빈 안내문("아직 없어요"), 입력칸 안내 글씨.
  3. 그대로 둔 **기능 색**: 고른 탭(파랑), 빨간 날·밀림(빨강), 입력 미리보기 한 줄
     (할 일 파랑 / 일정 보라), 입력칸의 [할 일]/[📢 일정] 토글, 삭제·경고(빨강), 메모판 노랑.
- 색 값은 `index.css`의 `--line-task / --line-event / --line-plan / --line-done / --line-off`
  한 곳에서 관리 — 색을 바꾸려면 그 값만 고치면 된다.
- 구현: 카드는 `--line` 변수 하나로 줄 색을 받아 같은 방식(안쪽 그림자)으로 그린다
  (`.task-item`, `.event-block`, `.day-block`). 달력 칩은 왼쪽 테두리.

## 색 예외 (의도된 것)
- **메모판(스티커) 노랑** (2026-07-03): 오늘 탭의 "날짜 없는 할 일" 판은 스티커 메모라는
  은유를 살리기 위해 연한 노랑 배경을 사용. "강조"가 아니라 "구역 구분"용이므로
  색 최소화 원칙의 예외로 인정. 그 외 새 색 추가는 계속 금지.
- ~~**우선순위 점 색**~~ → **2026-09-28 우선순위 제거와 함께 없어짐** (사용자 결정, F02 R13).
  아래는 당시 기록: (2026-07-03) **신호등 은유** — 빨강(높음)·주황(중간)·초록(낮음)의 작은 점.
  장식이 아니라 **정보를 담은 색**(중요도)이고 면적이 아주 작아 예외로 인정.
  대신 우선순위 "글자 뱃지"는 제거해 총 시각 소음은 오히려 감소.
  (처음엔 낮음=파랑이었으나 "여유 있음=초록"이 더 직관적이라는 사용자 의견으로 변경)
- **빨간 날** (2026-09-28, F07 R10): 달력의 공휴일·일요일 날짜 숫자와 공휴일 이름은 빨강 —
  한국 달력 관례이자 **정보를 담은 색**(쉬는 날). 글자에만 쓰고 배경은 칠하지 않는다.
  "밀림" 빨강(굵은 글씨 + 분홍 배경 뱃지)과는 모양으로 구분된다.
- ~~**일정 연보라** (2026-09-28, F11 R5 · 사용자 결정): 일정은 어디에 보이든 연보라 바탕 +
  보라 글자 — 달력 칩, 달력 아래 목록, 오늘 탭 일정 블록, 입력칸의 [📢 일정] 토글.~~
  → **같은 날 "종류 색 = 가는 줄"로 바뀜** (위 절). 넓은 연보라 바탕과 보라 글자는 없애고
  보라는 줄에만 남김. 입력칸의 [📢 일정] 토글(고르면 보라 테두리 + 연보라 바탕)과 입력
  미리보기의 보라 글자는 할 일의 파랑과 짝이라 그대로.

## 화면 정리 (2026-11-17, 사용자 요청)
- **유지**: 흰 카드·검은 본문·종류별 왼쪽 4px 줄, 메모판 노랑, 탭 4개와 모든 저장·날짜 계산 규칙.
  (2026-11-26: 탭은 5개가 되고 왼쪽 세로 배치로, 앱 폭은 최대 1600px로 — F03 R2d "넓은 화면" 항목)
- **글자**: 시스템 글꼴을 입력칸·버튼까지 통일하고 제목·본문·보조 글씨의 크기와 행간을 구분.
  설치형 앱의 창 색과 시작 배경도 본문과 같은 옅은 회색으로 맞춤.
- **조작**: 검색·날짜·편집·삭제·구역 제목은 같은 굵기의 SVG 선 아이콘. 아이콘 버튼에는 이름과 툴팁,
  키보드 포커스 표시를 제공. 외부 아이콘·글꼴 라이브러리는 추가하지 않음.
- **선택·포커스 세부 규칙**: 할 일/일정 토글은 둘 다 테두리 없이 옅은 배경과 아이콘 색으로 선택 표시.
  상단과 달력 입력에 동일하게 적용. 입력 중인 영역은 할 일 파랑·일정 보라의 같은 굵기 테두리와
  옅은 바깥 강조를 사용하고, 날짜 버튼이나 편집칸으로 포커스를 옮겨도 종류의 색을 유지.
  일정과 할 일의 수정·삭제 아이콘 버튼은 같은 크기·안쪽 여백을 사용.
- **할 일 카드**: 제목·메모·날짜 묶음과 오른쪽 조작 버튼을 같은 행에 배치해 아래의 빈 버튼 공간을 제거.
  버튼은 마우스를 올리거나 키보드 포커스가 들어왔을 때 표시, 삭제 확인은 항상 보임.
- **오늘**: 1000px 초과 창은 왼쪽 계획·기록 / 오른쪽 오늘·이번 주 할 일. 그 이하에서는 기존 세로 순서.
  날짜 이동과 일정 블록은 양쪽에 공통으로 적용.
- **달력**: 날짜별 그림자 대신 한 장의 흰 달력과 얇은 격자선. 일정 글씨는 약 12.5px.
  오늘은 날짜 숫자에 원 테두리, 선택한 날은 칸 전체의 연한 배경과 테두리로 구분.
  공휴일·일요일 빨간 글자와 종류별 칩의 색 줄은 유지.
- **메모**: 저장된 3열 배치와 끌기 기능은 유지. 연한 노랑, 제목 아래 구분선, 긴 문장의 줄바꿈·행간 정리.
- **검증 기준**: 오늘·메모·달력·전체·검색에서 내용과 조작이 겹치지 않고, 좁은 창에서 가로 넘침 없음.
  빠른 입력, 편집·완료, 날짜 이동, 검색, 키보드 조작과 빌드 확인.
